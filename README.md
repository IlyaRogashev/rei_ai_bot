#  AI Telegram Agent 

Это оч умный(нет) тг бот по имени Рей. Моя цель создать имитацию общения с человеком т.к. я ебаный социофоб и мне просто в прикол этим занниматься.
Сделайте пж вид что я уже допилил веб поиск.

- **Интеллектуальный поиск:** Бот сам решает, нужен ли ему интернет (через DuckDuckGo), чтобы ответить на ваш вопрос.
- **Дневник памяти:** Функция суммаризации диалогов для сохранения контекста общения.
- **Асинхронность:** Быстрая работа на `telegram`.

##  Технологии
- **Язык:** Python 
- **ИИ Модель:** meta-llama/Meta-Llama-3-8B-Instruct (via Hugging Face Inference API)
- **Поиск:** DuckDuckGo Search API
- **Инструменты:** `huggingface_hub`, `python-dotenv`, `duckduckgo_search`

##  Быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com/fckingNoTomorrow/rei_ai_bot.git
cd rei_ai_bot
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка окружения
Создайте файл `.env` в корневой папке и добавьте туда свои ключи:
```env
TELEGRAM_TOKEN=ваш_токен_бота
AI_TOKEN=ваш_hf_access_token
```
Создайте для бота папку diaries чтобы Рей было где хранить свои дневники

### 4. Запуск
```bash
python main.py
```

##  Как работает поиск (Web Search)
Проект использует двухуровневую проверку запроса:
1. **Классификатор:** Нейронка анализирует запрос пользователя. Если он содержит вопросы о фактах, новостях или неизвестных терминах (например, "Кто такой Wifiskeleton?"), активируется модуль поиска.
2. **Парсинг:** Скрипт собирает топ-3 результата из сети и подкладывает их в системный промпт модели как "Актуальные данные".

##  Структура проекта
- `main.py` - точка входа, обработка сообщений Telegram.
- `bot_mind.py` - формирование запроса ии, ведение дневника
- `web_search.py` - логика работы с поисковиком и классификация запросов.
- `model_context.txt` - системные инструкции для личности ИИ.
- `prompt_for_diary.txt` - правила для создания записей в дневнике.
